# Карта проекта

[Открыть интерактивную памятку](architecture.html).

Скачайте `architecture.html` и откройте браузером: интернет, сборка и зависимости не нужны.
При просмотре исходника HTML на GitHub интерактивная страница не запускается; для просмотра используйте локальный файл или опубликованную статическую страницу.

## Что внутри

- сценарии initial scan, MODIFY, DELETE, recovery, reconciliation и OVERFLOW;
- карточки всех Java-классов и моделей;
- FileTask против FileInfo, статистика при повторных событиях;
- интерактивный пример трёх реализаций handle;
- ошибки и ограничения текущего восстановления;
- потоки, очереди, BarrierTask, StopTask и прерывания;
- реализованный lifecycle, порядок shutdown и оставшиеся интеграционные шаги;
- сводная таблица связей между компонентами.

Памятка сверена с исходниками 2026-09-17. `FileIndexerService` уже содержит
проверенный lifecycle и shutdown; ближайший шаг — перевести на него `Main`.
После изменения поведения обновляйте соответствующие карточки и сценарии в `architecture.html`.

Для размещения в GitHub Pages подготовлена папка `docs`: входная страница — `index.html`, основная памятка — `architecture.html`. В настройках публикации репозитория потребуется выбрать нужную ветку и папку `/docs`. Публикация в рамках создания памятки не выполнялась.
